Użycie indeksu tablicy zamiast unikalnego id jako klucza (key) w React jest błędem, ponieważ podczas operacji takich jak usuwanie, dodawanie czy sortowanie elementów, React traci powiązanie między węzłami DOM a stanem komponentów. Może to prowadzić do błędów renderowania, nieprawidłowego zachowania kontrolek oraz spadku wydajności przy ponownym uzgadnianiu (reconciliation) drzewa DOM.
